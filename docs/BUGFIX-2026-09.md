# BUGFIX-2026-09 — milestones m4-close → m7 (before/after per item)

Follow-up to the m0–m3 fixes. Every item below states the lie/failure first,
then the fix and where it lives. Test files: `tests/test_m4_mcp_hardening.py`
(17 tests), `tests/test_m5_bridge_contracts.py` (9 tests).

## m4-close — providers / MCP / tools (remainder)

- **LLM accounting dropped `key_alias`.** Before: `_record()` wrote the alias
  to JSONL but the `llm_calls` INSERT had no such column — per-key spend was
  unauditable. After: migration v16 adds `key_alias` + `error_kind` columns
  (`schema/v0016_llm_key_alias.py`); both INSERTs name them
  (`providers/client.py`).
- **Terminal failures left no accounting trace.** Before: `complete()` raised
  and nothing was logged — /cost showed gaps. After: `_record_failure()`
  writes a zero-token row with `finish_reason="error"` + structured
  `error_kind` to JSONL and DB.
- **MCP session expiry (HTTP 404) surfaced as a fatal error.** Before: the
  `_session_id` was cleared but the call failed. After: exactly one
  re-initialization + one retried call inside `MCPClient.call()`
  (`connectors/mcp_client.py`); anything beyond one retry stays a failure.
- **Slow MCP servers burned crash-loop budget.** Before: every timeout called
  `_record_crash()` — 3 slow calls paused a healthy-but-slow server. After:
  `_is_timeout_error()` classifies timeouts as liveness failures (error
  returned, no crash recorded) in `call()`, `list_tools()`, startup.
- **Removed provider keys kept serving pooled connections.** Before:
  `remove_key()` deleted the row but the cached AsyncOpenAI client survived.
  After: `evict_client()` drops the `(base_url, alias)` entry
  (`providers/client.py` + `providers/manager.py`).
- **Browser tab ids collided after close.** Before: `tab{len(_pages)}` reused
  numbers — a new tab could steal a live tab's id and leak the page handle.
  After: caller id only if unused, else uuid suffix; open/close/switch run
  under `_state_lock`; opens route through `_page()` so a connected CDP
  browser is used (`connectors/builtin/browser.py`).
- **Pooled LLM sockets leaked at shutdown.** Before: `aclose()` existed but
  nobody called it. After: bridge `lifespan` closes clients on shutdown
  (`universe_desktop_bridge/app.py`).
- **Archive scope check duplicated the gate and broke legit paths.** Before
  (m4): handler-level `_within_scope` rejected pytest tmp dirs the capability
  gate (`path:glob:./**`) would have allowed. After: removed — the gate owns
  scope; the handler keeps only the zip-slip member-name check
  (`connectors/builtin/misc.py`). Caught by `test_archive_zip_unzip_roundtrip`.

## m5 — bridge contracts, events, voice

- **Soft failures read "completed".** Before: `gt.status = "completed"` on any
  exception-free return. After: status derives from `summary.success`;
  `gt.error` carries the summary error; existing errors are never clobbered
  by shallower ones (`universe_desktop_bridge/app.py` + `voice.py`).
- **project_id/title needed a side-UPDATE.** Before: bridge UPDATE after
  `run_goal`. After: `run_goal(..., project_id=, title=)` persists metadata
  itself (best-effort for old schemas).
- **Rings filled only with a connected UI.** Before: `add_event` ran solely
  in the WS loop — no UI meant no refill data. After: a process-wide bus
  consumer feeds rings from boot; the WS loop forwards the seq-stamped copy;
  `goal_events` exposes `dropped`; bus tracks per-subscriber drops
  (`observability/events.py`, `state.py`, `app.py`).
- **Ring overflow was silent.** Before: oldest events dropped with no count.
  After: `GoalTask.dropped` counts evictions; TTL pruner
  (`prune_expired`, 30 min) evicts terminal goals from the live registry
  (DB rows stay).
- **Provider-halt existed twice.** Before: pre-classify + in-loop copies with
  drifting formats. After: single `record_provider_halt()` helper
  (`core/agent/orchestrator.py`).
- **Orphan sweep stole other sessions' goals.** Before: all `status='running'`
  rows swept. After: scoped to the bridge's own `session_id` (+unowned rows).
- **Voice: handshake failure disguised as dead bridge; partial frames
  dropped; awake channel never slept; STT forced English; whisper double-load
  race; TTS failure invisible; no preflight.** After: accept-then-refuse with
  clean error; carry buffer for partial frames; 60 s awake timeout + 30 s
  segment cap; `stt_language` from Settings; whisper singleton lock; TTS
  errors stay their own event (never flip session status); `voice_hello`
  carries `stt_ready/tts_ready`; `voice_enabled` default unified to False
  (`universe_desktop_bridge/voice.py`, `app.py` DESKTOP_DEFAULTS).
- **Endpoints hid init failures; /api/providers read the whole JSONL per
  poll.** After: `init_error` in 503/voice rejects; tail-read (last 4 KB).
