# Universe Memory System — مواصفة المطابقة

الملف المرفق `universe-memory-system.html` هو **المرجع الحاكم** لهذا الإصدار. أعيد نقل المشهد من مصدره إلى Three.js مع بياناته الأصلية، لذلك لا تعتمد التجربة على صورة ثابتة أو محاكاة HTML بديلة.

| منطقة المرجع | تطبيقها في الواجهة المعاد بناؤها | معيار عدم التغيير |
|---|---|---|
| الشريط الأيسر | هوية Memory System، تنقل Universe/L1–L4/Core/Rules، مؤشرات الإحصاء وحالة البيانات. | يبقى شريطًا مضغوطًا غنيًا بالمعلومات على سطح المكتب. |
| المشهد المركزي | محرك Three.js أصلي بمجرة حلزونية، أنظمة شمسية، نجوم وكواكب وكويكبات وسدم وثقوب وقابلية السحب والتكبير. | يظل هو مساحة التشغيل المحورية، لا خلفية زخرفية. |
| الشريط العلوي | بحث الذاكرة، مفاتيح الطبقات L1–L5، إعادة ضبط المشهد وحالة البيانات. | يظل فوق الـcanvas وبالتناسب التقني الكثيف نفسه. |
| اللوحة اليمنى | Universe Overview ثم قوائم أو تفاصيل الكائن المختار، مع المقاييس والعلاقات. | تتغير بحسب التنقل أو اختيار عنصر، ولا تتحول إلى بطاقة تسويقية عامة. |
| شريط الحالة السفلي | Gravity Engine، Mem Sync، عدّاد العقد، المهمة النشطة والتقدم وRefresh. | يبقى مرئيًا ودقيقًا ومنخفض الارتفاع. |
| اللغة البصرية | فضاء قريب من الأسود، بنفسجي مخفف، teal للإشارة، وJetBrains Mono مدمج مع Space Grotesk للعلامة فقط. | لا يحل محله زجاج كثيف أو hero سينمائي أو ألوان ساطعة واسعة. |

## تفاصيل الواجهة المضافة بحذر

أُضيفت طبقة تحبّب دقيقة، علامة Universe أوضح، وتعليمات مشهد منخفضة الكثافة. هذه التفاصيل تدعم القراءة والتحكم من دون تعديل هندسة المرجع أو منافسة المجرة بصريًا.

## حدود هذا النموذج

بيانات الذاكرة المعروضة هي **بيانات العرض الأصلية المرفقة مع المرجع**. زر Refresh يعيد تحميل المشهد محليًا، ولا توجد في هذه المرحلة أي قراءة مباشرة من Universe Backend أو SQLite أو Local API.

## تحقق التفاعل المنقول

| التفاعل | النتيجة في المعاينة |
|---|---|
| التنقل إلى `Stars · L3` | تحولت اللوحة اليمنى إلى قائمة النجوم التسعة نفسها مع بقاء مشهد Three.js نشطًا. |
| اختيار `Fix auth bugs in login` | انتقلت اللوحة إلى بطاقة STAR، وعُرضت Brightness والعلاقات وكتلة Crystallized Knowledge، كما ركّزت الكاميرا على نظام web development. |
| البحث بـ`REST API design` ثم Enter | عثر المشهد على الذاكرة المطلوبة، وركّز الكاميرا عليها وعرض بطاقة STAR المرتبطة بالمهمة التابعة. |
| مفتاح `L5` | فعّل طبقة Dark Matter Grid المرجعية داخل مشهد Three.js مع الحفاظ على الطبقات الأخرى. |
| العودة إلى `Universe View` | أعادت النظرة العامة إلى اللوحة اليمنى واستدعت وضع الكاميرا الواسع المطابق لعرض المرجع. |
| `REFRESH` من شريط الحالة | يعيد بناء مشهد البيانات المرفق محليًا، ويعرض حالة مزامنة مؤقتة قبل العودة إلى `DEMO DATA`. |

كما فُحصت الواجهة على شاشة ضيقة؛ تتحول الشريط الجانبي إلى صف أيقونات، وتبقى مفاتيح الطبقات والبحث والمشهد واللوحة قابلة للوصول ضمن ترتيب رأسي.
