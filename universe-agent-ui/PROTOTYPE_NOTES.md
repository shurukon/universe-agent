# Universe Agent Desktop UI — Prototype Notes

هذه النسخة هي **نموذج واجهة أمامية تفاعلي فقط**، صُممت لاختبار تجربة Universe Agent على سطح المكتب قبل توصيل النظام الحقيقي.

| العنصر | حالة النموذج | ما الذي يمثله الآن |
|---|---|---|
| Voice Mode | محاكاة تفاعلية | تبديل بصري لحالات الاستعداد والاستماع والتفكير والرد، من دون التقاط صوت أو TTS حقيقيين. |
| Text Chat | محاكاة تفاعلية | إرسال رسائل محلية وردود واجهة صادقة، من دون اتصال بـUniverse Core. |
| Memory Lens | تفاعل واجهة مكتمل | خريطة ذاكرة قابلة للفتح، عقد قابلة للتركيز والفحص، وبطاقات سياق. |
| Command Palette | تفاعل واجهة مكتمل | اختصار `Cmd/Ctrl + K` لتجريب الانتقال بين الأوضاع والطبقات. |
| Settings | تفاعل واجهة مكتمل | تفضيلات محلية مثل تقليل الحركة، ولا تحفظ إلى backend بعد. |

## طريق التكامل التالي

سيستبدل ربط **Local API/IPC** وevent streaming حالات المحاكاة بالـUniverse Orchestrator، الذاكرة، الـSkills، حالات التنفيذ والصوت الحقيقي. لا تستورد طبقة الواجهة SQLite أو Python internals مباشرة.

## تحقق الواجهة

تم فحص البناء بـTypeScript وVite. كما فُحصت نقاط الدخول الرئيسة في المعاينة: تبديل Voice/Chat، النواة وحالاتها، Memory Lens، عناصر الذاكرة، Command Palette، والإعدادات. لا توجد صلاحيات أو مفاتيح أو بيانات تشغيل حقيقية ضمن هذا المشروع.

| فحص معاينة حي | النتيجة |
|---|---|
| زر `Talk to Universe` | ينتقل من `SYSTEM READY` إلى `LISTENING` ويُظهر إشعار محاكاة صريحًا. |
| مبدّل `Voice / Chat` | ينقل المستخدم إلى محادثة مركزية مع بقاء الذاكرة في عدسة عائمة فقط، من دون sidebar. |
| مؤلف المحادثة | يقبل طلبًا بلغة طبيعية، يضيفه إلى السجل، ثم يعرض رد واجهة يصرّح بأن المسار المقترح جزء من المحاكاة. |
| Memory Lens | تفتح فوق المحادثة في طبقة مستقلة قابلة للإغلاق، مع بقاء المحادثة في الخلفية من دون تغيير للتخطيط. |
| عقدة ذاكرة | النقر على عقدة يعرض بطاقة «Memory Context» قابلة للإغلاق، لذلك لا يعتمد الوصول إلى التفاصيل على hover وحده. |
| اختصار `Escape` | يغلق Memory Lens وبطاقة الذاكرة والإعدادات عبر مسار موحد، ويبقي وضع المحادثة الحالي فعالًا. |
| اختصار `Cmd/Ctrl + K` | يفتح Command Palette كطبقة سياقية؛ يُلتقط في مرحلة capture كي لا يكتب حرف الاختصار داخل حقل البحث. |
| نافذة الإعدادات | تظهر كـoverlay مستقل مع وصف واضح بأن عناصرها تفضيلات واجهة محلية فقط. |
| تفضيل تقليل الحركة | ينتقل المفتاح إلى حالة التفعيل ويضيف فئة `reduce-motion` التي توقف الحركة غير الضرورية في الواجهة. |
